# Motorola Sales Dashboard – Power BI

## 📊 Project Overview

An interactive sales dashboard built using Microsoft Power BI to analyze sales performance, transaction trends, customer ratings, payment methods, brands, mobile models, cities, and day-wise sales.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📌 Key Performance Indicators

- **Total Sales:** 769M
- **Total Quantity:** 19K
- **Transactions:** 4K
- **Average:** 40K

## 📈 Dashboard Features

- Total Sales by City
- Total Quantity by Month
- Customer Ratings Analysis
- Transactions by Payment Method
- Brand-wise Sales Analysis
- Sales by Mobile Model
- Sales by Day Name
- Interactive filters for:
  - Mobile Model
  - Payment Method
  - Brand
  - Day Name
  - Month
